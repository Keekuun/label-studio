# 标尺工具示例

## 功能说明

标尺工具允许标注员在图片上绘制测量线，用于：

1. **测量距离**：显示每根线的长度（像素）
2. **比较比例**：当绘制多根线时，自动计算并显示比例（如 1:2, 1:2:3）
3. **颜色区分**：不同线使用不同颜色，便于区分

## 使用方法

1. 启动开发服务器：
   ```bash
   cd web
   yarn lsf:serve
   ```

2. 访问 http://localhost:3000

3. 使用标尺工具：
   - 点击工具栏中的标尺图标（尺子图标）
   - 在图片上点击起点，拖拽到终点
   - 释放鼠标完成绘制
   - 重复绘制多根线以查看比例

## 显示效果

- **单根线**：显示长度，如 "125px"
- **多根线**：每根线显示长度和比例，如 "125px (1) | Ratio: 1:2:3"
- **颜色**：每根线自动分配不同颜色（红、青、蓝、橙、绿、黄、紫、天蓝）

## 配置示例

```xml
<View>
  <Ruler name="ruler" toName="image" />
  <Image name="image" value="$image" />
</View>
```

## 数据格式

标尺区域的数据格式：

```json
{
  "x1": 10.5,
  "y1": 20.3,
  "x2": 45.2,
  "y2": 35.7,
  "coordstype": "perc"
}
```

- `x1, y1`: 起点坐标（百分比 0-100）
- `x2, y2`: 终点坐标（百分比 0-100）
- `coordstype`: 坐标类型（"perc" 或 "px"）

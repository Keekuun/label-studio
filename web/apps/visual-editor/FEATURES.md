# Visual Editor 功能清单

## 核心功能

### ✅ 已实现功能

#### 1. 组件管理
- [x] 从组件面板拖拽组件到画布
- [x] 组件树可视化显示
- [x] 组件选择（点击选择）
- [x] 组件删除（按钮 + Delete 键）
- [x] 组件嵌套支持

#### 2. 属性编辑
- [x] 动态属性表单
- [x] 支持多种属性类型：
  - string（文本输入）
  - number（数字输入）
  - boolean（开关）
  - select（下拉选择）
  - color（颜色选择）
- [x] 属性验证（必填项检查）
- [x] 属性依赖处理（toName 自动获取 Object 组件）
- [x] 实时同步到组件树

#### 3. XML 转换
- [x] 组件树 → XML（生成）
- [x] XML → 组件树（解析）
- [x] 自动类型转换（字符串、数字、布尔值）
- [x] 自动识别组件分类
- [x] 错误处理和提示

#### 4. 工具栏功能
- [x] 清空所有组件
- [x] 复制 XML 到剪贴板
- [x] 下载 XML 文件
- [x] 导入 XML 文件

#### 5. 预览功能
- [x] 实时 XML 预览
- [x] 预览面板标签页切换（预览 / XML 代码）
- [x] XML 代码编辑器（只读）
- [x] 复制 XML 按钮

#### 6. 键盘快捷键
- [x] Delete/Backspace - 删除选中组件
- [x] 预留复制、粘贴、撤销、重做接口

#### 7. 组件库
- [x] View（视图容器）
- [x] Image（图像）
- [x] Text（文本）
- [x] RectangleLabels（矩形标签）
- [x] Rectangle（矩形）
- [x] Labels（标签）
- [x] Choices（选择）
- [x] Choice（选项）
- [x] Label（标签项）
- [x] Header（标题）

## 技术特性

### 技术栈
- React 18
- TypeScript
- Jotai（状态管理）
- @dnd-kit（拖拽功能）
- Ant Design（UI 组件）
- DOMParser（XML 解析）

### 架构特点
- 组件化设计
- 类型安全（TypeScript）
- 响应式状态管理（Jotai）
- 不可变数据更新
- 错误边界处理

## 使用场景

### 适用场景
1. 运营人员配置 Label Studio 模板
2. 快速创建和修改标注配置
3. 学习和理解 Label Studio XML 结构
4. 配置模板的版本管理

### 不适用场景
1. 需要复杂逻辑的配置（建议直接编辑 XML）
2. 需要自定义组件的场景
3. 需要编程式配置的场景

## 性能优化

### 已优化
- 使用 useMemo 缓存计算结果
- 组件树操作使用不可变更新
- 防抖处理（待实现）

### 待优化
- 虚拟滚动（大量组件时）
- 懒加载（组件元数据）
- 代码分割

## 已知限制

1. 目前支持 9 种组件类型（可扩展）
2. XML 导入时，某些复杂属性可能无法完全还原
3. 预览面板需要正确集成 playground 的 PreviewPanel
4. 画布内拖拽排序功能待完善

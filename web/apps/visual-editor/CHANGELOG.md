# 更新日志

## [0.1.0] - 2024-12-XX

### 新增功能
- ✨ 可视化拖拽编辑器基础功能
- ✨ 组件面板（9种组件类型）
- ✨ 画布区域（组件树可视化）
- ✨ 属性面板（动态表单编辑）
- ✨ 预览面板（实时预览 + XML 代码）
- ✨ 工具栏（清空、复制、下载、导入 XML）
- ✨ XML 导入/导出功能
- ✨ 键盘快捷键支持
- ✨ 组件删除功能

### 组件支持
- View（视图容器）
- Image（图像）
- Text（文本）
- RectangleLabels（矩形标签）
- Rectangle（矩形）
- Labels（标签）
- Choices（选择）
- Choice（选项）
- Label（标签项）
- Header（标题）

### 用户体验
- 🎨 改进空状态显示
- 🎨 添加拖拽提示
- 🎨 优化组件卡片样式
- 🎨 改进视觉反馈和动画

### 技术特性
- TypeScript 类型安全
- Jotai 状态管理
- @dnd-kit 拖拽功能
- Ant Design UI 组件
- DOMParser XML 解析

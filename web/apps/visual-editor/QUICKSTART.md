# Visual Editor 快速开始指南

## 🚀 快速开始

### 1. 安装依赖

```bash
cd web
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities antd
```

### 2. 启动开发服务器

```bash
yarn visual-editor:serve
```

访问 http://localhost:4201

## 📖 5 分钟教程

### 步骤 1: 添加图像对象

1. 从左侧组件面板找到 **"图像"** 组件
2. 拖拽到中间画布区域
3. 在右侧属性面板设置：
   - **名称**: `img`
   - **数据源**: `$image`

### 步骤 2: 添加矩形标签

1. 从组件面板找到 **"矩形标签"** 组件
2. 拖拽到画布中（可以拖到 Image 组件上作为子组件，或拖到画布作为同级组件）
3. 在属性面板设置：
   - **名称**: `tag`
   - **关联对象**: 选择 `img`（会自动出现在下拉列表中）
   - **选择模式**: `single` 或 `multiple`

### 步骤 3: 查看结果

1. 底部预览面板会自动显示生成的 XML
2. 切换到 "XML" 标签页查看代码
3. 点击 "复制 XML" 按钮复制配置

### 步骤 4: 导出配置

- 点击工具栏的 **"下载 XML"** 按钮
- 或点击 **"复制 XML"** 复制到剪贴板

## 🎯 常用操作

### 选择组件
- 点击画布中的组件节点

### 删除组件
- 点击组件节点上的删除按钮（悬停或选中时显示）
- 或选中组件后按 **Delete** 键

### 编辑属性
- 选中组件后，在右侧属性面板编辑
- 修改会实时同步到组件树和 XML

### 导入配置
- 点击工具栏的 **"导入 XML"** 按钮
- 选择 XML 文件即可导入

## 💡 提示

1. **组件顺序很重要**：通常先添加 Object 类型组件（如 Image），再添加 Control 类型组件（如 RectangleLabels）

2. **toName 属性**：Control 组件的 `toName` 必须引用已存在的 Object 组件的 `name` 属性

3. **实时预览**：所有修改都会实时反映在预览面板中

4. **键盘快捷键**：
   - `Delete` / `Backspace` - 删除选中组件

## 🐛 遇到问题？

### 预览不显示
- 检查 XML 格式是否正确
- 查看浏览器控制台是否有错误

### 组件无法拖拽
- 确保已安装 `@dnd-kit/core` 依赖
- 刷新页面重试

### 属性编辑不生效
- 确保已选中组件
- 检查属性值格式是否正确
